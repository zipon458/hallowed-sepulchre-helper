# Hallowed Sepulchre Helper

A RuneLite plugin for the Hallowed Sepulchre agility course.

## Features

- **Route/Floor Timer** - Tracks floor times and tick-perfect target times
- **Overall Timer** - Tracks total run time
- **Crossbow Statues** - Highlights active crossbowmen
- **Knight Statues** - Shows knight statues danger zones
- **Lightning** - Highlights lightning strike locations
- **Portals** - Highlights active yellow and blue portals
- **Wizard Statues** - Shows fire tiles and incoming fire tiles
- **Bolt & Sword Projectiles** - Highlights tiles for bolts and swords
- **Obelisk Highlighting** - Highlights the obelisk on your last eligible floor or when time runs out
- **Player Immunity** - Visual indicator when immune after blue portal teleport
- **Skill Obstacles & Coffins** - Highlight skill obstacles and coffins

Most features can be toggled on/off and colors can be customized.

Feel free to submit any issues, bugs or suggestions on the plugin repo issues tab.
